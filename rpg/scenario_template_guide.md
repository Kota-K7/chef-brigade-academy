# RPG シナリオ記述テンプレート ＆ 執筆ガイド (History & Story 統合版)

このガイドは、歴史体験RPG（History）および修業ストーリー（Story）のシナリオ原稿をシステム認識可能な形式で安全に執筆するための設計書およびルールです。

---

## 1. ⚠️ 不具合防止のための重要執筆ルール（必須対策）

過去のデータ作成において、コピペミスや複数人のセリフ混同によるデータ崩れが多発しました。以下のルールを必ず厳守してください。

### ① 【重要】話者マーク（絵文字）の廃止
以前使用していた `👑` や `🛡️`、`👨‍🍳` などの話者マーク（絵文字）は**廃止**されました。
シナリオ原稿の記述時は、絵文字を使わず、直接キャラクターの登録名またはIDを指定してください。

### ② 【超重要】複数人の会話を1行にまとめる場合は必ず `→` で接続する
会話が切り替わる際、改行を多く使うと縦にスペースを消費するため、複数人のセリフを同じイベント枠内でコンパクトに記述したい場合は、必ず **`→`（矢印）** で接続してください。
これにより、システム側で誤作動を起こさずにセリフを自動で個別オブジェクトへ分解できます。

*   **NG（絶対禁止 - 境界が判別できずパースが壊れます）:**
    ```text
    Vercingetorix
    「周囲の村に触れ回れ。ローマ軍に作物を渡すなと」 副官：「はっ！ 作戦の準備を」
    ```
*   **OK（推奨 - 省スペースで正確に分割されます）:**
    ```text
    Vercingetorix:「周囲の村に触れ回れ。ローマ軍に作物を渡すなと」→副官:「はっ！ 作戦の準備を」
    ```

### ③ 【重要】セリフ行の中に `└`（解説マーク）や解説テキストを直接混ぜない
解説や文法補足（`└`）は、必ずセリフの**次の行**に分けて記述してください。
*   **NG（絶対禁止）:**
    ```text
    Girl:「Ça va ?（大丈夫？）」└ 説明行: aller vers + 場所 = 「〜へ向かう」
    ```
*   **OK（正しい書き方）:**
    ```text
    Girl:「Ça va ?（大丈夫？）」
    └ 説明行: aller vers + 場所 = 「〜へ向かう」
    ```

### ④ 【重要】カギカッコ `「` `」` のペアを必ず一致させる
*   セリフにカギカッコを使用する場合は、必ず開き `「` と閉じ `」` が1対1でペアになるようにしてください。片方（`」` のみなど）が欠けた表記はパースエラーとなります。
*   基本のセリフでカギカッコを表示しない方針の場合は、`「` も `」` も一切使用しないでください。

### ⑤ 【例外】同時発話（複数人の同時発声）の扱い
`「「Oui Chef !!!」」` のように、複数名が同じ言葉を同時に発話するシーンでは、二重カギカッコ `「「` `」」` を使用することがシステム上正しく認められています。この場合はペアが合っていれば修正の必要はありません。

## 2. 📝 History (歴史体験RPG) 記述テンプレート

歴史体験RPGでは、歴史のイベント進行とともに文法やフレーズを学びます。

### 構成要素と書式

#### A. 会話ブロック (Dialog)
キャラクターの会話です。立ち絵画像や位置、セリフに紐づく解説（学習ポイント）を定義できます。

```text
Caesar:「Bonjour! 新人くん、我が陣営へようこそ。」
└ Caesar: ローマ軍の総司令官。
└ 解説: Bonjour
  意味: 「おはよう」「こんにちは」
  フランス語で最も一般的に使われる朝・日中の挨拶表現です。
```
*   **キャラクター指定**: `Caesar:` や `Caesar：「...」` のように名前コロンで開始します。
*   **説明行**: `└` と `→` までの間の文はキャラクターの説明や注釈として画面上に表示されます。
*   **学習ポイント**: `└ 解説: [タイトル]` とそれに続く箇条書きで、解説パネルを自動生成して表示します。

#### B. 解説・チュートリアル画面 (Tutorial)
バトルの前にプレイヤーに読ませる文法カードや歴史背景カードです。

```text
■事前解説 (Préparation)
目標: 練習問題の前に、以下の文法・表現をおさらいしましょう。

▼ ページ 1: 存在動詞 être
フランス語の最も基本的な動詞「être」の現在形活用です。
- Je suis (私は〜です)
- Tu es (君は〜です)

▼ ページ 2: 歴史背景
カエサル率いるローマ軍はガリアへ侵攻しました。
```

#### C. バトルブロック (Battle)
プレイヤーのHP、敵のHP、出題するクイズの条件タグを指定します。

```text
⚔️ 戦闘開始 (Battle)
敵キャラクター: ローマ衛兵
敵のHP: 3
被ダメージ: 2
出題範囲（タグ指定）:
- #greetings : 2問
- #subjects : 1問
```

## 3. 📝 Story (修行ストーリー) 記述テンプレート

修行ストーリー（キャリアモード）では、レストランでの修行ステップに合わせたクイズが出題されます。

### 構成要素と書式

#### A. 会話ブロック (Dialog)
基本的な記述方法は History RPG と同様です。

```text
Saeki:「どれどれ……（味見して）本当だ。よくできているね。」
└ Saeki: レストラン「La Nouvelle Étoile」の副料理長（スーシェフ）。
```

#### B. バトルブロック (Battle)
修行ストーリーのバトルは、以下の固定の問題数（HP）で構成されます。難易度と出題タグを指定します。
*   **基礎問題 (Basic)**: 5問出題 (`enemyHp: 5`)
*   **応用問題 (Applied)**: 7問出題 (`enemyHp: 7`)
*   **総合復習 (Mixed)**: 10問出題 (`enemyHp: 10`)

```text
⚔️ 戦闘開始 (Battle)
敵キャラクター: 佐伯 (シェフ)
難易度: 基礎 (5問)
出題範囲（タグ指定）:
- #greetings : 2問
- #subjects : 1問
- #etre : 2問
```

---

## 4. 🏷️ クイズで利用可能なカテゴリタグ (Tags)

シナリオ内で出題範囲を指定する際は、問題集 `questions_db.json` に登録されている以下のタグを使用してください。

*   `#greetings` : 挨拶表現（Bonjour, Merci など）
*   `#etre` : 動詞 être の活用
*   `#avoir` : 動詞 avoir の活用
*   `#subjects` : 主語人称代名詞
*   `#articles` : 冠詞（定冠詞・不定冠詞）
*   `#negation` : 否定表現
*   `#numbers` : 数字の綴り
*   `#plurals` : 複数形
*   `#units` : 計量・単位（litre, kilo など）
