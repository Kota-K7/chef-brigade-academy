# History RPG (歴史体験) - コンセプトシート

## テーマ・目的
古代〜現代のフランスを舞台に、各地方の歴史的背景、歴史的な出来事、指示された挨拶・語彙・文法表現を学びます。

## 学習対象レベル
- フランス語上級まで

## 各章と学習内容 
ご要望通り、各章の歴史テーマ、学習内容、および例文のみを一覧にまとめました。

| 章           | 歴史テーマ            | 主要文法・学習内容                                                                | 到達会話・例文                                                     |
| :---------- | :--------------- | :----------------------------------------------------------------------- | :---------------------------------------------------------- |
| **第0章**     | ガリア以前            | アルファベット・発音、名詞の性、冠詞、être、avoir、c’est/ce sont、主語代名詞、基本形容詞、否定 (ne…pas)      | *C’est un couteau.* *Je suis apprenti cuisinier.*           |
| **第1章**     | ガリア戦記            | 第一群(-er)・第二群規則動詞、疑問文、疑問詞 (où/quand/pourquoi/comment)、前置詞 (à/de/dans/sur) | *Où est le sel ? Il est sur la table.*                      |
| **第2章**     | フランク王国           | 近接未来 (aller + 不定詞)、命令形、目的語代名詞(基礎)、不規則動詞 (faire/prendre/mettre/venir)     | *Prenez les légumes. Mettez la sauce.*                      |
| **第3章**     | カペー朝             | 複合過去 (passé composé)、avoir/êtreの選択、過去分詞の一致(基礎)、比較級、最上級                   | *J’ai préparé le dîner. C’était le meilleur plat.*          |
| **第4章**     | ヴァロワ朝            | 半過去 (imparfait) と複合過去の使い分け、関係代名詞 (qui/que)、接続詞 (parce que/mais/donc)     | *Le chef qui travaille ici prépare la viande.*              |
| **第5章**     | ブルボン朝 (ルイ13・14世) | 条件法現在、丁寧表現、si文 (現実条件)、代名詞 y / en                                         | *Je voudrais changer la sauce. On pourrait ajouter du vin.* |
| **第6章**     | ブルボン朝末期          | 接続法基礎、感情表現、必要・義務表現 (il faut que / je veux que / je préfère que)          | （主体的な提案や指示）                                                 |
| **第7章**     | 革命（前編）           | 接続詞強化、論理表現 (cependant / pourtant / en revanche / tandis que)             | （論理的な主張や反論）                                                 |
| **第8章**     | 革命（後編）           | 受動態、代名動詞、使役 (faire + 不定詞)                                                | *Le plat est préparé par le chef.*                          |
| **第9章**     | 第一帝政             | 大過去（過去完了）、条件法過去、仮定表現                                                     | *Si j’avais su…*                                            |
| **第10章**    | 19世紀の体制動揺        | 文法総復習（時制整理、接続法、長文読解、会話表現）                                                | フランス厨房で働けるレベル                                               |
| **第11章**    | 第三共和政            | ニュアンス表現、同義語、丁寧な批評                                                        | *Ce plat manque légèrement d’équilibre.*                    |
| **第12-13章** | 世界大戦             | 新聞表現、抽象語彙、比喩表現                                                           | （高度な文献や批評の読解）                                               |
| **第14-15章** | 現代（第四・五共和政）      | 文化的表現、議論、プレゼン、料理哲学                                                       | （シェフ・経営者としての高度な対話）                                          |
