# Story (修行ストーリー) シナリオ記述・設定テンプレート

このテンプレートは、修行ストーリー（キャリアモード）のシナリオ原稿をシステム認識可能な形式で記述するための設計書です。

## 1. シナリオ構成のルール

ストーリーの進行（シーケンス）は以下の要素で記述します。

### A. 会話ブロック (Dialog)
キャラクターの会話です。立ち絵画像や位置、セリフに紐づく解説（学習ポイント）を定義できます。

**書式例:**
```text
👨‍🍳Jean-Pierre（ジャン＝ピエール）
「Bonjour! 新人くん、厨房へようこそ。」
└ 👨‍🍳Jean-Pierre（ジャン＝ピエール）レストラン「La Nouvelle Étoile」の Chef（料理長）
└ 解説: Bonjour
  意味: 「おはよう」「こんにちは」
  フランス語で最も一般的に使われる朝・日中の挨拶表現です。
```
- **話者マーク**: 👨‍🍳Jean-Pierre などのシンボルでキャラクターを自動認識します。
- **説明行**: └ と → までの間の文はキャラクターの説明や注釈として画面上に表示されます。
- **学習ポイント**: └ 解説: [タイトル] とそれに続く箇条書きで、解説パネルを自動生成して表示します。

### B. 解説・チュートリアル画面 (Tutorial)
バトルの前に強制的に読ませる文法書や参考資料カードです。各話のテーマに対応する文法書の内容が表示されます。

**書式例:**
```text
■事前解説 (Préparation)
目標: 練習問題の前に、以下の文法・表現をおさらいしましょう。

▼ ページ 1: 存在動詞 être
フランス語の最も基本的な動詞「être」の現在形活用です。
- Je suis (私は〜です)
- Tu es (君は〜です)

▼ ページ 2: 基本の挨拶
- Bonjour (おはよう / こんにちは)
- Merci (ありがとう)
```

### C. バトルブロック (Battle)
修行ストーリーのバトルは、以下の固定の問題数で構成されます。

- **基礎問題 (Basic)**: 5問出題 (`enemyHp: 5`)
- **応用問題 (Applied)**: 7問出題 (`enemyHp: 7`)
- **総合復習 (Mixed)**: 10問出題 (`enemyHp: 10`)

**書式例:**
```text
⚔️ 戦闘開始 (Battle)
敵キャラクター: ジャン＝ピエール (シェフ)
難易度: 基礎 (5問)
出題範囲（タグ指定）:
- #greetings : 2問
- #subjects : 1問
- #etre : 2問
```

## 2. 利用可能なクイズ・バトルのカテゴリタグ (Tags)

問題集 `questions_db.json` に紐づく以下のタグを使用して、バトルで出題する問題を抽出できます：

- `#greetings` : 挨拶表現（Bonjour, Merci, S'il vous plaît など）
- `#etre` : 動詞 être の活用
- `#avoir` : 動詞 avoir の活用
- `#subjects` : 主語人称代名詞（Je, Tu, Il, Elle, Nous, Vous, Ils, Elles）
- `#articles` : 冠詞（定冠詞・不定冠詞）
- `#negation` : 否定表現
- `#numbers` : 数字の綴り
- `#plurals` : 複数形名詞・冠詞
- `#units` : 計量・単位

## 3. 自動選択される出題形式 (Format Engine)

抽出された問題は、以下のいずれかの形式で自動的にレンダリングされます：

1. **スペル入力 (typing)**: 85%の確率で自動選出。正解候補リスト（`acceptedAnswers`）と一致するかどうかを判定。
2. **4択問題 (choice)**: 15%の確率で自動選出。
3. **並び替え (scramble)**: 単語チップを順にクリックして正しい文を完成させる。
4. **穴埋め (cloze)**: 文中の `[word]` 部分を隠し、キーボード入力または選択肢で答えさせる。
5. **マッチング (matching)**: 左右の単語や表現をペアで結びつける。
